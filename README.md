# 麻雀成績集計アプリ v6

## 起動方法
1. Python をインストール
2. このフォルダでコマンドプロンプト / PowerShell / ターミナルを開く
3. 次を実行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## v6 の主な変更
- 百の位を5捨6入してから素点を計算
- 20,500点 → 20,000点 → -10P
- -9,500点 → -9,000点 → -39P
- -9,600点 → -10,000点 → -40P
- 1位の最終ポイントを「1位以外のポイント合計の符号反転」に変更
- 同率1位の場合は1位グループで残差を均等分配
